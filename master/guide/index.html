Getting Started ​

A zoom and pan plugin for Chart.js >= 3.0.0

Panning can be done via the mouse or with a finger. Zooming is done via the mouse wheel or via a pinch gesture. Gesture recognition uses the browser's native Pointer Events — no extra dependency is required.

Installation ​

bash
> npm install chartjs-plugin-zoom

TIP

Important Note: For Chart.js 2.6.0 to 2.9.x support, use version 0.7.7 of this plugin. Documentation for v0.7.7 can be found on GitHub.
